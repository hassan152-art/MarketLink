(re-run it any time: `python3 tools/generate_images.py`).

  - markets / farmers / products: backend/src/data/*.js  (`image` / `images`)
  - landing + cinematic story:     frontend/src/data/landingScenes.js, productStory.js

Folders: markets/, farmers/, products/, story/  (+ farm-1, farmer-1, products-1, pickup-1, market-1 for the landing scenes)
